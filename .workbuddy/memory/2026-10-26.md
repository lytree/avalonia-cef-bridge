## 上游基准刷新 + Tauri 2.12 核心 API 面等价实现

### 起因
`gap-analysis.md §1.2` 只刷新了**插件**版本（tauri 2.12.5 / sql 2.6.0 / updater 2.14.0），把"没有新增官方插件"当成"能力面无变化"，漏登 tauri **2.12.0 核心**新增的 9 项公共 API 面。本轮补齐基准并落地三项。

### 基准文档
- `docs/design/gap-analysis.md` 新增 **§1.3 核心 2.12 API 面复核**：12 项逐条列上游形态 / Tarui 状态 / 处置；新增 **§1.4 验证证据**。

### 落地三项（完整链路：Contracts → 命令/权限 → Shell/插件 → capability → TS → 测试 → 文档）
1. `core:window|set-fullscreen-on-monitor`（Tauri 2.12 #14926）
   - `SetFullscreenOnMonitorOptions(X, Y, Label?)`；`AvaloniaWindowService.FullscreenOnMonitor`：先退全屏 → 如需换屏则改 Position → 再进全屏（全屏状态改 Position 在部分平台无效）；坐标落在所有显示器外 **no-op**（对齐上游，不伪造成功）。
   - 纯函数 `Tarui.Shell/FullscreenTarget.Resolve(PixelRect[], PixelPoint) → index|-1`（internal + InternalsVisibleTo Shell.Tests）。
   - `-other-window` 变体；TS `Window.setFullscreenOnMonitor(x, y)`。
2. `core:app|exit`（Tauri 2.12 #14767，把 app.exit 从 process 插件提升到 core）
   - `CorePlugin(IAppShutdown)` 改构造注入；`AddCorePlugin()` 用 `TryAddSingleton<IAppShutdown, NoopAppShutdown>()` 兜底（组合根的真实实现覆盖）；退出仍走合作式 stop，不引入 `Environment.Exit`。
   - TS `app.exit(code)`；barrel 以 `exit as exitApp` 导出，避免与 process 模块的 `exit` 冲突。
3. sql 2.6.0 `LoadOptions.autoCreate`
   - `SqlLoadOptions(Connection, bool? AutoCreate = null)`（null = 上游默认 true）。
   - 新可选接口 `ISqlCreateModeDriver.Open(connectionString, createIfMissing)`（只有 SQLite 实现；其他驱动忽略该 flag）；`SqliteConnectionString.Normalize(..., createIfMissing)` 在 false 时用 `Mode=ReadWrite`；`SqliteService` 预检文件缺失给明确错误。
